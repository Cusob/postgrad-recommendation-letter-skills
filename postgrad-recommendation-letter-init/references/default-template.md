# 默认自荐信结构

默认 DOCX 资产位于 `assets/default-letter-template.docx`。它只提供通用版式和段落骨架，不提供任何具体个人、导师、学校或论文事实。

默认模板包含两个独立的论文理解段落，分别用于承载两篇代表性论文。建议结构：称呼与问候；身份和申请目的；学业情况；科研经历；工程与竞赛经历；第一篇论文理解；第二篇论文理解；能力连接与边界；研究生阶段计划；附件与交流；感谢；姓名和日期，共 14 个正文段落。

两段论文使用独立占位符：`PAPER1_*` 和 `PAPER2_*`。执行时应分别选择和压缩两篇真正具有代表性的论文，不要把两篇论文重新合并到同一段，也不要为了填满第二段加入代表性不足的论文。

这是无用户底稿时的语义参考，不是所有用户 DOCX 都必须转换成的固定结构。生成默认底稿契约时，仍然以实际 DOCX 的段落、run 和 section 为准。
