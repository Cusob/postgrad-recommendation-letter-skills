# 底稿适配与写作

## 底稿

用户上传的模板或上一轮确认满意的 DOCX 是完整底稿。先通读其全部正文、表格、页眉页脚和可见内容，再以当前简历和用户最新确认事实为准逐段审查：

- 保留版式、段落组织和用户明确想保留的语气；
- 修正或删除与当前简历不符的姓名、学校、成绩、项目、奖项、论文和联系方式；
- 替换旧导师、旧论文、旧研究兴趣和旧申请目标；
- 不只替换占位符，也检查普通正文中隐藏的不匹配内容；
- 不把底稿中的事实自动当作简历事实。

没有用户模板时使用内置默认 DOCX 的通用结构。

## 写作

自荐信应自然回答：为什么联系这位导师，读懂了哪篇代表性论文或哪条研究主线，自己的哪些经历可以迁移，还缺什么，研究生阶段准备如何学习。语气真诚、谦逊、正式，避免空泛赞美、机械翻译摘要、过度承诺和无证据的研究匹配。

论文段只能使用本轮实际读取的 PDF 内容。可以写具体问题、机制、实验和局限，但不能把学生写成已经掌握导师论文中的方法。简历中的待确认字段不进入正式事实句；用户当前消息明确确认的内容可用于本轮，但不自动写回长期状态。

生成 DOCX 时另存为 `自荐信_目标导师姓名.docx`，不要覆盖源底稿、简历或默认模板。保留底稿的版式和签名结构，优先进行局部内容修改。
