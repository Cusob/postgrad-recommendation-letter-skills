# 调研与论文选择

## 导师调研

像处理正常复杂学术调研一样，使用当前可用的搜索、浏览、页面访问和文件下载能力。先确认“是哪位导师”，再确认单位、职称、研究方向、研究路径和论文归属。打开搜索结果和相关页面，不把搜索片段当最终证据。用户提供的主页应当认真读取，但只是定位线索，不能替代学校/学院页面、论文列表、作者页面和其他相关来源的交叉判断。

不要预设固定搜索引擎、网站顺序或尝试次数。根据当前线索选择最有价值的下一步；一个入口失败时换一条路线，不机械重复同一失败页面。目标是找到导师真实的研究主线和可读取的代表性论文。

## 代表性论文

先从导师研究路径和公开成果中建立候选池，再选通常两篇：

- 第一篇最能体现导师核心研究主线；
- 第二篇体现阶段变化、当前重点、方向拓展，或与学生经历存在真实而克制的连接。

代表性判断看研究主线中的作用、导师的署名/贡献、发表成果本身的重要性和证据可靠性。学生匹配度和全文获取便利性只帮助在相近候选之间取舍，不能把边缘论文提升为代表作。最终报告简要说明入选和替代理由，不需要人为打分。

## 全文追踪

题名、DOI、导师论文列表和作者信息是导航线索。自主追踪能够真正返回全文的入口，实际下载到任务目录，检查文件确为 PDF，核对题名、作者、年份、版本或 DOI，并读取本地文件。可以使用正式版本、作者版本、accepted manuscript、机构仓储、实验室页面、预印本等可靠版本。

如果一个入口返回 HTML、登录页或错误脚本，不把它当论文，也不要因此宣布任务失败；根据题名、作者、机构、DOI和搜索结果继续寻找新的入口。只有没有新的合理路径、无法完成本地全文读取时，才停止论文特定写作。

## 轻量记录

建议任务目录结构：

```text
学校_导师/
├── 研究报告.md
├── 论文候选与来源.md
├── 恢复说明.md
├── papers/
└── sources/
```

记录实际使用的来源、论文文件路径、版本和失败线索即可，不建立复杂状态机或固定错误分类表。
