# 调研、候选论文与证据账本

## 调研目标

目标是回答“是哪位导师、研究主线如何发展、哪些成果真正能代表这些主线、哪些内容有足够证据写进信件”，而不是完成固定网站清单。使用当前可用的 Codex 搜索、浏览、页面访问和下载能力，随线索选择下一步最有价值的动作。

主页是定位线索。继续核验学校/学院、团队、作者、成果、出版和全文来源。不要把搜索片段或单一主页当作完整画像。

## 研究覆盖

先整理可确认的早期基础、核心发展、阶段转折和近期方向；实际阶段由导师成果决定，不强行凑“早中晚”。如果公开资料只覆盖少数阶段，要明确说明。

高置信度候选论文数量不超过 3 篇时，先回查是否遗漏了机构页、成果列表、作者索引、题名/DOI 线索和作者版本，尽量继续扩展。补充检索仍不超过 3 篇时，说明“确认成果较少或公开资料不完整”，并评价研究画像是否足够支撑正文；不能直接断言导师成果少。

停止扩展的理由应是合理检索饱和：新增结果重复、无法消歧，或不再带来新的代表性候选。找到两篇可下载 PDF 不是停止理由。

## 候选论文记录

推荐在 `论文候选与来源.md` 中以表格或逐条记录保存：

```text
题目：
完整作者：
年份/期刊或会议：
DOI/唯一标识：
导师作者角色：
同名消歧与身份置信度：
研究阶段与研究主线：
代表性判断：
证据等级：PDF_FULLTEXT_READ / FULLTEXT_NON_PDF / ABSTRACT_ONLY / METADATA_ONLY / IDENTITY_UNVERIFIED
来源与文件路径：
状态：selected / alternative / excluded / pending
取舍理由：
```

同名或归属不清的成果保留为 `IDENTITY_UNVERIFIED` 或 `pending`，不要静默混入导师成果。

## 代表性与可得性

先按研究主线和学术代表性选择候选，再在代表性相近时考虑全文可得性。学生经历匹配度只能作为表达取舍的辅助，不能取代代表性。对最终选入论文努力获取可读取全文；失败时记录入口、失败原因和替代候选。

## 证据边界

只有本地 PDF 实际读取后才能标记 `PDF_FULLTEXT_READ`。完整 HTML/XML 可以标记 `FULLTEXT_NON_PDF`，但不应写成 PDF 精读；摘要和元数据不能支持具体实验或机制表述。

## 恢复

复用已经核验的来源和 PDF。新增检索只补缺口，不覆盖源文件，不因为一次失败清空候选记录。
