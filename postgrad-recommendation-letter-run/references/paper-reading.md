# 论文精读

只对已经下载并实际读取的本地 PDF 使用“精读”措辞。逐篇记录：

1. 基本信息：题目、完整作者、年份、期刊/会议、DOI、关键词和本地路径。
2. 研究问题：解决什么问题，为什么重要，传统方法或现有方案有什么不足。
3. 核心方法：输入与表示、模型/算法/控制器/系统结构，以及最关键的机制。用通俗但准确的中文解释。
4. 创新类型：问题、方法、系统、实验验证或应用场景；不凭空写“首次”。
5. 实验与结果：数据、仿真或硬件、基线、指标、主要结果、消融和失败条件。区分作者声称与实验实际支持。
6. 局限：作者明确写出的限制、隐含假设、未测试条件和可合理延伸的方向。
7. 信件切入点：提炼 2-3 句自然表达，写清具体问题、方法理解和学生的真实学习连接，不复制摘要。

论文案例不自动等于工业部署，仿真不自动等于实体效果，标题和摘要不自动支持实验细节。遇到不确定处降低表述强度或标为未知。
